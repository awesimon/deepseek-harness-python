# DeepSeek Harness Python Runtime

English | [中文](README.zh.md)

The Python workspace contains the PyCordis backend runtime, Agent Spine, Plugin Manager, Browser Bridge server, control plane, scaffolder, and their tests. The public import root is `harness`.

Run commands from the repository root with `uv --directory python ...`, or change into this directory and use the local `uv` project. The repository-level architecture and bilingual usage guide live in [../README.md](../README.md) and [../README.zh.md](../README.zh.md).
