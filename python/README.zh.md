# DeepSeek Harness Python Runtime

[English](README.md) | 中文

Python Workspace 包含 PyCordis Backend Runtime、Agent Spine、Plugin Manager、Browser Bridge Server、Control Plane、Scaffolder 及其测试。公开 Import Root 是 `harness`。

从仓库根目录执行命令时使用 `uv --directory python ...`，也可以进入此目录使用本地 `uv` Project。仓库级架构和双语使用指南见 [../README.md](../README.md) 与 [../README.zh.md](../README.zh.md)。
